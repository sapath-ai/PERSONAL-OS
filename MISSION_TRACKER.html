                  Performance Mode
                  Off — full visual effects

                  Turns off blur, glow, and animation effects app-wide (header blur, card glows, entrance animations, chart animation). These effects normally run on the GPU almost for free — on a device with no dedicated GPU they're done in software instead, which is what causes stutter. This trades the polish for a completely static, instant-response UI.

                  Daily Backup
                  No folder chosen — backups will download to your browser's Downloads folder

                  In Chrome/Edge/Opera on desktop, "Choose Backup Folder" lets a saved backup file be written straight into a folder you pick — no repeated file dialogs after the first time. Firefox, Safari, and mobile browsers don't support that, so backups there always go to your normal Downloads folder instead — still automatic, just not to a custom folder. Starting at 8 PM each day, if you haven't backed up yet, a reminder will pop up automatically so it doesn't get forgotten.
